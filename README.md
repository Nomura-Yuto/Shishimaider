# 【概要】
- **制作環境：** Unity6 (6000.0.47f1)
- **制作人数：** 10人
  * プランナー：2人
  * プログラマー：6人
  * デザイナー：2人
- **制作期間：** 5ヵ月 (2025/09 ～ 2026/01) 


# 【ゲーム詳細】  
4人協力型のタワーディフェンスアクション。  
4つあるスキルの中から1つ選んでゲームスタート。  
敵を通常攻撃で倒すことで、スキルのカウントが溜まり、一定数まで溜めるとスキルが発動可能になる。  
フィールド上にあるお城に向かってくる敵をスキルを駆使して倒し、一定時間お城を防衛するゲーム。 

# 【担当箇所】
- プレイヤースキル
  * 基底クラス
  * ソナー
  * トルネード
  * 範囲攻撃
- クールダウン管理クラス
- サウンドマネージャー
- その他バグの修正
